# Community Standards

Envoy community spaces are for concrete product feedback, reproducible reports,
technical questions, integration notes, and serious discussion about agent
coordination.

Be direct, specific, and good-faith. Do not harass people, spam threads, post
private data, publish live invite codes, or use issues/discussions for security
disclosure.

Maintainers may edit, hide, lock, or remove content that is abusive, off-topic,
unsafe, or not useful to the project.

Report security issues privately to `security@statecraft.fyi`.
